Anthologies and separate works

The volumes contain 30 separate tales. Name a story to focus a discussion, or name several to compare them. Editorial introductions and notes are separate.

Import source data

The three configured sources are Gutenberg ebooks 2147 and 2148 and The Philosophy of Composition from the Poe Society. Load all three without API keys, then index. JSON imports accept raw Gutenberg text or the original essay HTML as objects with url and text.

Expected format
[{"url":"https://www.gutenberg.org/cache/epub/2147/pg2147.txt","text":"Full Gutenberg text including START and END markers..."}]

Gutenberg wrappers and essay site navigation, page labels, and editorial notes are excluded from embeddings. Raw downloads are retained locally. Pinecone indexing requires its key and index host in .env; Local answers need no API key; the optional OpenAI column uses OPENAI_API_KEY. Download the local model once using python app.py --download-model. Coverage includes Volumes 1 and 2 and the composition essay. After upgrading, load and reindex all three sources.
